# v2 — Наведение порядка: учебный пример RAG и переименование консольного чата

**Статус:** реализовано 2026-11-25 (утверждён 2026-11-25)
**Ветка:** `chore/rag-example` (от `main`)
**Исполнитель реализации:** автор проекта (вручную)

## Цель

Явно отделить учебный пример RAG без фреймворков и БД (`src/rag-manually.ts`) от рабочих чатов, дать ему команду запуска и привести документацию в соответствие с новым именем скрипта консольного чата (`chat:cli` вместо `dev`).

## Вне рамок v2

- Превращение учебного примера в полноценный чат (многократные вопросы, история диалога).
- Хранение векторов учебного примера между запусками.
- Изменения в веб-чате (`server.ts`, `public/`) и в консольном чате, кроме переименования скрипта.

## Шаги

### Блок A. Перенос учебного примера и удаление отладочного кода

- **A1.** Создать папку `src/examples/`.
- **A2.** Перенести `src/rag-manually.ts` в `src/examples/` с именем, из которого понятно, что это учебный пример.
- **A3.** Перенести `src/cosine.ts` в `src/examples/`: он используется только учебным примером.
- **A4.** Убедиться, что в `src/` не осталось импортов перенесённых файлов.
- **A5.** Удалить `src/view-chunks.ts` и его вызов и импорт в `src/index.ts` (решение D4).
- **A6.** Убедиться, что в `src/` не осталось ссылок на `view-chunks`.

### Блок B. Запуск и описание примера

- **B1.** Добавить в `package.json` скрипт `example:rag` для запуска учебного примера.
- **B2.** Добавить в начало файла примера комментарий: что это учебная демонстрация RAG без фреймворков и БД, эмбеддинги считаются при каждом запуске, отвечает на один вопрос.

### Блок C. Переименование скрипта консольного чата

- **C1.** Скрипт консольного чата называется `chat:cli` вместо `dev` (уже сделано автором, не закоммичено).
- **C2.** Заменить упоминания `npm run dev` в `docs/indexing.md` на `npm run chat:cli`.
- **C3.** Убедиться, что в `docs/` не осталось упоминаний старого имени скрипта, кроме исторических записей в `docs/plans/v1-plan.md`.

### Блок D. Проверка

- **D1.** `npm run example:rag` запускается и отвечает на вопрос по базе знаний.
- **D2.** `npm run chat:cli` и `npm start` работают как раньше.
- **D3.** `npm run format:check` проходит.

### Блок E. Ревью и слияние

- **E1.** Код-ревью диффа ветки относительно `main`.
- **E2.** Исправить принятые замечания.

| # | Решение | Обоснование |
|---|---|---|
| D1 | Учебный пример остаётся в проекте, но не развивается до чата | Показывает весь RAG (эмбеддинги, косинусное сходство, top-k, промпт) без абстракций LangChain; как чат он дублировал бы два существующих |
